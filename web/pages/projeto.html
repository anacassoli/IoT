Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de criar um sistema de monitoramento ambiental utilizando tecnologias de Internet das Coisas (IoT). O sistema coleta dados por meio de sensores conectados ao microcontrolador e envia essas informações em tempo real para um Dashboard Web.

🎯 Objetivo

Monitorar as condições do ambiente em tempo real, acompanhando informações como temperatura, umidade e qualidade do ar.

⚙️ Hardware

O projeto utiliza um microcontrolador ESP32 conectado aos sensores responsáveis pela coleta das informações ambientais.

🌐 Arquitetura

Os dados são enviados pelo ESP32 utilizando o protocolo MQTT. O broker recebe as mensagens e o Dashboard Web se conecta através de WebSockets para exibir os dados em tempo real.
